# 🩺 AI Healthcare Assistant – Personalized Medical Recommendation System

## 📌 Overview

AI Healthcare Assistant is an intelligent disease prediction and medical recommendation platform powered by Machine Learning and Flask. The system analyzes user-provided symptoms, predicts the most likely disease, and provides personalized healthcare recommendations including medications, precautions, diet plans, and workout suggestions.

This project aims to bridge the gap between users and basic healthcare guidance by providing quick and accessible preliminary recommendations.

---

## ✨ Features

### 🔍 Disease Prediction

* Predicts diseases based on user-entered symptoms.
* Utilizes a trained Machine Learning classification model.
* Provides fast and accurate predictions.

### 💊 Medicine Recommendations

* Suggests medicines related to the predicted disease.
* Displays treatment-related information.

### 🥗 Diet Planning

* Recommends suitable diet plans.
* Helps users follow healthy nutrition habits during recovery.

### 🏃 Fitness & Workout Suggestions

* Provides workout and physical activity recommendations.
* Supports overall wellness and recovery.

### ⚠️ Precaution Guidelines

* Displays important preventive measures.
* Helps users avoid complications and improve recovery.

### 📖 Disease Description

* Provides detailed information about predicted diseases.
* Improves user awareness and understanding.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/AI-Healthcare-Assistant.git
cd AI-Healthcare-Assistant
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
